Make sense of CAD 3rd-party diagnostic logs

A fast, offline-first log analysis tool: call tree visualization, performance analytics, and AI-assisted root cause analysis, all in one portable Windows app.

What is this?

CAD 3P Log Browser parses and visualizes the diagnostic logs produced by CAD third-party integrations, turning a flat wall of text into something you can actually navigate: a call tree with duration-based color coding, an API-centric view for cross-referencing, timeline and flame-graph visualizations, and a performance dashboard that surfaces the slowest and most-frequent calls automatically.

It also includes an AI Assistant that can summarize a log, suggest root causes for a specific slow call using its real parent-chain context, and flag anomalies against a saved baseline — all built to work fully offline by default, with optional API-backed analysis if you configure a provider.

  • Search, filter, and bookmark across huge log files without choking
  • Compare two logs side by side and see exactly what changed
  • Export filtered logs, call trees, performance data, and full analytics reports
  • Dark mode, configurable thresholds, and a portable, no-install .zip distribution
