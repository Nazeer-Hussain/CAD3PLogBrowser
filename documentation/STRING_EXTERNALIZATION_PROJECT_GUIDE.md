## Naming Conventions

### Constants
- **Dialog Titles:** `DialogTitle`
- **Labels:** `Label[Purpose]` (e.g., `LabelFindWhat`)
- **Buttons:** `Button[Action]` (e.g., `ButtonFindNext`)
- **Checkboxes:** `Checkbox[Option]` (e.g., `CheckboxMatchCase`)
- **Messages:** `Message[Purpose]` (e.g., `MessageNotFound`)
- **Format Strings:** `[Purpose]Format` (e.g., `StatusFilteredFormat`)
- **Status:** `Status[State]` (e.g., `StatusSearching`)
- **Tool Tips:** `ToolTip[Control]` (e.g., `ToolTipOpen`)

### Organization
Group constants by functional area:
1. Dialog Title
2. Labels
3. Buttons
4. Checkboxes/Radio Buttons
5. Combo Box Items
6. Group Titles
7. Tool Tips
8. Status Messages
9. Dialog Messages
10. Format Strings
