# Settings Dialog Height Adjustment

## Problem
The AI & Integration tab content was truncated because the Settings dialog was too small to display all the content.

## Solution
Increased the Settings dialog height to accommodate the AI & Integration tab's content.

## Changes Made

### Before:
```
Dialog Height:     450px
TabControl Height: 390px
Buttons Y:         414px
```

**Issue**: AI & Integration content extends to Y=516px, but TabControl is only 390px tall, causing truncation and requiring scrolling.

### After:
```
Dialog Height:     600px (+150px)
TabControl Height: 540px (+150px)
Buttons Y:         564px (+150px)
```

**Result**: All AI & Integration content now fits comfortably within the visible area without scrolling.
