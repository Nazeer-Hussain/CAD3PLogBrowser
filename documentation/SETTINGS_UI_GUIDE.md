## Tab Organization

### 1. **Appearance**
- Theme (Light/Dark)
- Toolbar icon size
- Show toolbar
- Highlight color

### 2. **Tabs & Layout**
- Visible tabs configuration
- Start-up tab selection
- Default tree view

### 3. **Log Font**
- Font family
- Font size
- Font style (Bold/Italic)
- Font preview

### 4. **Files & Behavior**
- Default open folder
- Max recent files
- Snippet file suffix

### 5. **Performance**
- Fast/Slow call thresholds
- Max file size for list view
- Auto-filter performance tab

### 6. **Integration**
- Grok URL
- Claude API Key (legacy)
- Claude API toggle (legacy)

### 7. **AI Settings** ? NEW
- AI provider configuration
- Model selection
- API keys
- Ollama server settings
- Temperature & tokens
- Privacy & conversation settings
- Connection testing

### 8. **Updates**
- Auto-check on startup
- Check interval
- Manifest URL
- Update history
