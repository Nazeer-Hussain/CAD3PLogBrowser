## Grouped Sections

### 1?? AI Provider Section
**Purpose**: Select and configure AI provider

**Controls**:
- Enable AI Features checkbox
- Provider dropdown (Mock, Anthropic, GitHub, Ollama, etc.)
- API Key field (for cloud providers)
- Ollama Server URL (for Ollama only)
- Model dropdown (provider-specific)

**Height**: 165px

### 2?? Model Configuration Section
**Purpose**: Fine-tune AI behavior

**Controls**:
- Temperature slider (0.0 - 2.0)
- Temperature value label
- Max tokens numeric input
- Enable streaming checkbox

**Height**: 110px

### 3?? Privacy & Conversation Section
**Purpose**: Privacy and history settings

**Controls**:
- Redact sensitive data checkbox
- Remember conversation checkbox
- Max messages numeric input

**Height**: 75px

### 4?? Legacy Integration Section (Deprecated)
**Purpose**: Backward compatibility with old integration methods

**Controls**:
- Grok URL text field
- Claude API Key text field (old)
- Use Claude API checkbox (old)
- Deprecation warning label

**Height**: 100px

**Note**: ?? Clearly marked as deprecated, encourages users to migrate to new AI Provider system.

### 5?? Connection Testing
**Purpose**: Validate configuration

**Controls**:
- Test AI Connection button
- Status label (shows success/error)

**Height**: 28px

## Migration Guide for Users

### If you were using Legacy Claude Integration:

**Before**:
1. Go to Integration tab
2. Enter Claude API key
3. Check "Use Claude API"

**After**:
1. Go to AI & Integration tab
2. In "AI Provider" section:
   - Select "Anthropic Claude" from dropdown
   - Enter API key
   - Select model
3. Your old settings are preserved in Legacy section
4. Test connection
5. Save

**Benefits**:
- ? Better model selection
- ? Streaming support
- ? Conversation history
- ? Privacy controls
- ? More features!
